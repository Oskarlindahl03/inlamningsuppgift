# inlämningsuppgift

Inlämningsuppgift Java — kontohanteringssystem med arv och polymorfism.

## Struktur

```
inlämningsuppgift/
├── README.md
├── Docs/
│   └── Planeringsmall.md
└── src/
    ├── Main.java
    ├── Withdrawable.java
    ├── Account.java
    ├── SavingsAccount.java
    ├── CheckingAccount.java
    ├── StudentAccount.java
    ├── Transaction.java
    └── Bank.java
```

## Kör

```bash
javac src/*.java
java -cp src Main
```
